# Fonts

The face Cattery draws its grid with unless the settings name another:
JetBrains Mono Nerd Font Mono in its regular, bold, italic and bold italic
styles, the `JetBrainsMonoNerdFontMono-*.ttf` files of the `JetBrainsMono`
archive of the [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) v3.5.1
release, unchanged. Nerd Fonts made them from
[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) 2.304 by adding
the glyphs of the icon sets below, every glyph one cell wide.

The font is under the SIL Open Font License 1.1, as JetBrains Mono is and as
Nerd Fonts keeps every font it patches; JetBrains Mono reserves no font
name. Each icon set's glyphs stay under their authors' licence. Cattery
carries the font inside its executable, and ships these licence texts, in
`LICENSES/`, beside it in every package.
